Yearn allocation history · implementation scope · 15 September 2026

An explorable reference for Kong.

The agreed goal is an API implementation whose responsibilities and responses are aspirationally equivalent to Kong’s draft, with Envio supplying event evidence here.

Agreed scope

  • Keep the chart and action-detail routes. The detail route provides the data an inspector renders.
  • Keep the existing prepared full-action list as a diagnostic convenience.
  • Put Envio behind an event-reader interface. Reconstruct balances with historical RPC and prepare immutable Postgres responses.
  • Retire the legacy composite /api/allocations endpoint and checkpoint-backed ratio contract.
  • Preserve existing grouping behavior. An intervening deposit does not automatically split related keeper actions. The earlier proposal to enforce boundary-balance equality was withdrawn.
  • Use captured samples as reference material. Independent validation and a second production implementation are outside scope.

Implementation

Branch: codex/kong-allocation-reference. The source-neutral reader, Envio adapter, shared refresh pipeline, structured quality metadata and prepared chart/detail routes are implemented. Top-level run identity and chart asset metadata are included. RPC accounting is independent of Envio checkpoints.

Event completeness remains separate from accounting reconciliation. Missing coverage proof keeps a run provisional. Source evidence digests identify captured inputs without claiming a transactionally frozen upstream snapshot.
