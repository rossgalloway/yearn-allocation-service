What the current API means

EvidenceAddressConfiguration
Supported assigned allocatorAssigned contractRead using its family; successful zero remains zero
Custom contract or address without codeAssigned address remains visibleUnsupported or no-code status; unavailable ratios
Configuration RPC failureVerified assigned address remains visibleUnavailable status and null ratios
Explicit zero assignmentNull with cleared statusOld targets are cleared
Missing or inconsistent assignment evidenceUnavailable with a reasonNo factory or old allocator is substituted

Deployment identifies the interface family. Assignment identifies the address selected for the vault. Shared factory governance is never interpreted as a vault address. Supported signatures from custom addresses are indexed through the combined discovery ABI; arbitrary interfaces do not become supported merely because they are assigned.
